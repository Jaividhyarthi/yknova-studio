# YKNOVA Studio Storefront

## Publish on GitHub Pages
1. Create a new PUBLIC repo called `yknova-studio` at github.com/new.
2. Upload the *contents of this store folder* to the repo root (index.html, style.css, app.js, checkout-config.js and demos/).
3. In Settings > Pages, choose Deploy from a branch; main; /(root); Save.
4. When enabled, visit https://Jaividhyarthi.github.io/yknova-studio/ and verify every live preview.

## ACTIVATE PAID CHECKOUT (do this before advertising sales)
1. Create a real seller account on a digital-delivery platform, complete KYC and payout setup.
2. Create 3 digital products: Pulse Metrics (INR 799), Orbit Auth (INR 299), Flow Navigation (INR 199).
3. Upload each matching ZIP in the sibling `products/` directory to the digital delivery platform; NEVER to your public GitHub Pages repository.
4. Set each unique HTTPS product checkout URL in checkout-config.js.
5. Push updated checkout-config.js and test each payment URL, checkout price, email/receipt and download delivery.
